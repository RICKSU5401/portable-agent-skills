# Security

Do not publish credentials, account details, conversation exports, native provider logs or private handoff payloads. Use synthetic reproductions. A dedicated private security reporting channel has not been configured. Do not post sensitive vulnerability details publicly; request a private contact from the repository owner using a nonsensitive description. The upstream project's security address is not designated for this project.

These tools run with the caller's normal filesystem/process permissions. Their checks are not a sandbox. Supply only trusted policy/catalog/quota files and reviewed executable adapters. Never use generated text as shell code. Do not invoke administrative elevation, disable provider controls, or purchase capacity to work around a blocked result.

Digests provide integrity checks, not authentication. Check the sender, permissions, source version and actual files independently. Store real receipts outside the repository. Quota and capability declarations are evidence inputs requiring inspection, not cryptographic account proofs.
